# RUSTIC — Fighting Poverty & Climate Change

A responsive NGO website designed for **RUSTIC**, an organization working to reduce poverty and address climate change through community development, education, healthcare, environmental protection, and sustainable livelihoods.

* Responsive modern design
* Interactive location section
* Impact statistics
* Environmental and education sections
* Image gallery
* Smooth animations and interactions
* Mobile-friendly layout

## Technologies

* HTML5
* CSS
* JavaScript
* GitHub Pages
